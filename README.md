# AI Image Generation System using Stable Diffusion

## 📖 Overview

The **AI Image Generation System** is a web-based application that generates high-quality images from natural language prompts using the **Stable Diffusion** model. The project integrates **Django**, **Flask API**, **Google Colab**, and **MySQL** to provide a complete end-to-end AI image generation workflow.

This project was developed as a **Final Year Engineering Project**.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/nikhilsable5050/ai-image-generation-system.git
```

Move into the project directory

```bash
cd ai-image-generation-system
```

Install the required Python packages

```bash
pip install -r requirements.txt
```

# ▶️ Running the Project

## Step 1 : Run the Google Colab Notebook

Open

```
google-colab/Stable_Diffusion_Colab.ipynb
```

using **Google Colab**.

Run all the cells.

Wait until a public Cloudflare URL is generated.

Example:

```
https://xxxx.trycloudflare.com
```

---

## Step 2 : Update Flask API URL

Open

```
aiimageproject/myapp/views.py
```

Replace

```python
FLASK_API_URL = "YOUR_COLAB_URL/generate-image"
```

Example

```python
FLASK_API_URL = "https://xxxx.trycloudflare.com/generate-image"
```

Also update

```python
base_url = "https://xxxx.trycloudflare.com"
```

using the same URL generated by Google Colab.

---

## Step 3 : Run Django Project (VS Code)

Open the project in **Visual Studio Code**.

Open a new terminal.

Move to the Django project directory

```bash
cd aiimageproject
```

Run the Django development server

```bash
python manage.py runserver
```

---

## Step 4 : Open the Application

Open your browser and visit

```
http://127.0.0.1:8000
```

Register or Login.

Enter a text prompt.

Click **Generate Image**.

The generated image will be displayed on the webpage and can be downloaded.

---

# 🔄 Project Workflow

1. User registers or logs into the application.
2. User enters a text prompt.
3. Django backend receives the request.
4. Backend sends the prompt to the Flask API.
5. Flask API forwards the prompt to the Stable Diffusion model.
6. Stable Diffusion generates the image.
7. Generated image is returned to the Django backend.
8. Django stores image metadata in the MySQL database.
9. Generated image is displayed to the user.

---

# 🗄️ Database

The MySQL database stores:

* User Information
* Login Credentials
* Prompt History
* Generated Image URL
* Image Metadata

> **Note:** The actual generated image is stored in the media folder, while only its path/URL and metadata are stored in the database.
